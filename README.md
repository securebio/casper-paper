# CASPER data paper

Data and code for:

Justen, L. et al. Deep untargeted wastewater metagenomic sequencing from sewersheds across the United States. medRxiv 2026.03.05.26345726 (2026) [doi:10.64898/2026.03.05.26345726](https://doi.org/10.64898/2026.03.05.26345726)

Raw sequencing data is on the NCBI SRA under BioProject PRJNA1247874.

## Setup

Python 3.11 or later.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`cartopy`, used only by the sampling map, needs the GEOS and PROJ system
libraries. On macOS `brew install geos proj`; on Debian or Ubuntu
`apt install libgeos-dev libproj-dev`.

## Running

Rebuild every figure and table:

```bash
python code/run_all.py
```

It runs from any directory and writes to `figures/` and `tables/`.

`code/index.qmd` produces the same outputs as a rendered notebook, with the
statistics and tables inline. It needs [Quarto](https://quarto.org) and must be
rendered from `code/`:

```bash
cd code && quarto render index.qmd
```

## Layout

| | |
|---|---|
| `data/` | inputs |
| `code/` | the scripts that read `data/` and write `figures/` and `tables/` |
| `figures/` | generated figures |
| `tables/` | generated tables |


### Inputs

Most of `data/` is per-sample output from the [SecureBio viral metagenomics
pipeline](https://github.com/securebio/nao-mgs-workflow). This repository does not run that pipeline.
